### #UT-020: System Status Shows "Deprecated"
**Status**: ✅ **FIXED** (Committed: 83fd00e)  
**Finding**: Settings page was calling `/api/jobs/health` which redirected to Celery endpoint  
**Root Cause**: Old job system endpoint returned `"status": "deprecated"` after Celery migration  
**Fix Applied**: Updated settings.html to call `/api/metadata-enrichment/celery/health` directly  
**Test Result**: Celery health endpoint returns proper status:
```json
{
  "status": "healthy",
  "message": "1 workers available",
  "workers": 1
}
```
**Action**: ✅ Fixed and committed to dev

### #UT-012: Enhanced Metadata Refresh Hangs
**Status**: ✅ **WORKING AS DESIGNED**  
**Finding**:
- Endpoint calls `await enrichment_service.enrich_video_metadata()` synchronously
- External API calls (IMVDb, MusicBrainz, etc.) genuinely take time
- 65-second timeout implemented (line 1596-1603 in videos.html)
- Message disappears after timeout or completion
- Could be improved by converting to background Celery job (future enhancement)

**Action**: None required - timeout mechanism working correctly
